# OptiScaler-Susemi v11.2-rc2 (experimental A-only candidate)

Use the [v11.2-rc2 direct-tag page](https://github.com/grim-susemi/OptiScaler-Susemi/releases/tag/v11.2-rc2) for the ZIP and checksum after publication. The [stable latest page](https://github.com/grim-susemi/OptiScaler-Susemi/releases/latest) is separate. The published rc1 is historical, not the recommended installer: its ASI loader removal could delete the installed loader when a recorded backup file or directory was missing.

## What changed

`tools/asi_loader_install.ps1` now refuses removal with a nonzero exit and preserves the installed loader and receipt when a recorded backup is missing. Existing valid-backup restore and original no-backup removal paths remain. The core `OptiScaler.dll` is byte-identical to rc1: SHA-256 `0eab8e59446d126fb25e35f83c87ffdf0fe6a3abb1084e6b480ad18234741c60`. The UAL binary, default INI, official Streamline helper and licenses are unchanged. The ZIP checksum is supplied separately in `SHA256SUMS.txt`; do not treat an old rc1 checksum as this candidate's checksum.

The owner approved reuse of the earlier game run and screen observation only for the byte-identical core DLL with SHA-256 `0eab8e59446d126fb25e35f83c87ffdf0fe6a3abb1084e6b480ad18234741c60` and its then-installed configuration. This is not a separate rc2 game run or a game test of the repaired installer; its removal behavior has separate fixture evidence. The one-run T11 limits remain: WMI start-event registration failed with `Access denied`, so the approved observation used log-change and process-exit monitoring instead; `ReShade.ini` had no pre-run SHA-256, so original-byte restoration cannot be proven. The observation does not establish a single cause for NR/ReShade coexistence. NR and unlocks stay opt-in. Keep existing mod/INI backups and verify SHA-256 when restoring. See [installation and rollback](../INSTALL-KO.md) and [ReShade-first load-order constraints](XEFG-NR-RESHADE-LOAD-ORDER.md).

## Distribution boundary

This is A-only. No RTX 20/30 B, SM86/SM75 kernel or NVIDIA runtime binary is bundled. The original official-helper exception applied only to source S `45a74ab66dbe5e1a0639e3ec3022b319961243e5` / published rc1 A ZIP `95e8384c51ab965444cc13116b0965e8da4f60febd32520740422a59e676e5fc`. The owner has now extended that exception to exactly the unchanged `Streamline_fetcher_windows.bat` and `tools/Get-StreamlineRuntime.ps1` in the rc2 A-only successor, subject to final source/ZIP byte verification against the approved helpers. Only explicit user invocation may fetch official NVIDIA-RTX/Streamline runtime DLLs; there is no download on install or B payload fetch. A supplied asset SHA-256 digest mismatch is blocked; without a supplied digest the computed hash is recorded only, and signature state is recorded, not enforced. This exception does not authorize bundling or redistribution of downloaded NVIDIA DLLs or B binaries in this ZIP. The MIT Ultimate ASI Loader and its license remain unchanged.

v11.2-rc2 is an experimental Susemi candidate, not a stable release or upstream merge. At the time this note was prepared, the candidate was local-only; these owner decisions alone did not approve a commit or publication. They also did not approve a tag, assets, default-branch update, rc1 page edit or game changes. Check the direct-tag page for publication status and final asset checksum.
